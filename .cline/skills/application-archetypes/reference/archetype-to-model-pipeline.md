## ARCHETYPE → MODEL → HUNT PIPELINE

When you load this skill, immediately:

```
1. Identify which archetype(s) the target fits
   - Some targets are hybrids (e.g., SaaS + Subscription + API Platform)
   - Load all applicable archetypes, merge attack surfaces

2. Load application-model-builder
   - Build 6-component model
   - Run assumption breaking for each workflow in priority list

3. Load business-logic-hunter
   - Execute patterns matching this archetype
   - Focus on "Pays Most" items first

4. Test in priority order
   - Each archetype has a numbered priority list above
   - Start at #1, don't skip to #4 just because it's easier
```
