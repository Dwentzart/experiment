## Confidence Scoring Matrix

| Confidence | Criteria | Action |
|-----------|----------|--------|
| **10/10** | أعيد إنتاجه 3+ مرات. PoC كامل. No false positive angle | Report immediately |
| **8-9/10** | أعيد إنتاجه. بعض الـ variables متغيرة | Report with caveat |
| **6-7/10** | أعيد إنتاجه مرة واحدة. احتمال FP موجود | Investigate more |
| **4-5/10** | نظرية. مش不复 reproducible باستمرار | Don't report yet |
| **0-3/10** | تخمين. لا دليل | Kill finding |
